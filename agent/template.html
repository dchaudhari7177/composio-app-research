06 · If I ran this at Composio

From a one-off table to a standing pipeline

feed

Run it on the request backlog

Point the agent at every app users ask for, nightly. New apps get a record in minutes instead of a research ticket.

route

Verdict decides the queue

build_now gaps go straight to toolkit engineering. with gate starts the paid-plan or app-review request. outreach goes to partnerships with the evidence attached.

watch

Re-check what changes

Auth deprecations and new MCP servers ship constantly (HubSpot is retiring legacy private apps in 2026). A diff on each re-run is a changelog for the catalog.

dogfood

Swap the tools for Composio's

The fetch, search and browser steps are plain functions. Composio's own search, browser and GitHub toolkits can replace them, and the review queue can land in Linear or Slack through Composio too.

07 · Proof

Run it yourself

The agent is a small Python package. It runs on a free local model (Ollama, qwen2.5:3b) or on Claude with one environment variable. Any app works, not just these 100.

# research one app that is not on the list
uv run python -m agent run --app "Calendly" --hint developer.calendly.com --out runs/calendly.json

# the full 100, then the loops, review queue and score
uv run python -m agent run
uv run python -m agent review
uv run python -m agent score
uv run python -m agent site
